# 07 - French translations

This file tracks French translations created, reused, updated or replaced for the NEFARAM-Rhiven setup.

- FR : Translated by Rhiven
- FR Nexus : Translations downloaded on Nexus Mods
- FR Confrérie : Translations downloaded on "La Confrérie des Traducteurs"

## Rules

- Do not assume an old translation is still compatible with the current mod version.
- Record the exact source mod version whenever possible.
- Keep translations separate from original mods when practical.
- Personal translations should also use the `- Rhiven` suffix when installed as independent MO2 mods.

## Field translation safety reference

- [Skyrim SE — safe / non-safe field reference (evolving draft)](guides/SKYRIM-FR-FIELD-SAFETY.md): includes NPC proper names versus generic NPC labels, Papyrus strings, VMAD, and contextual rules.
