# 06 - User Interface

## Stock NEFARAM UI stack

NEFARAM already contains a substantial UI stack including SkyUI, SkyHUD, TrueHUD, Dear Diary Dark Mode, Infinity UI, Compass Navigation Overhaul, I4 / B.O.O.B.I.E.S support, Knotwork, More Informative Console and related patches.

The current strategy is **not** to dismantle the existing stack. Dragonborn UI is installed lower in the left pane and allowed to overwrite the visual assets it is designed to replace.

## Dragonborn UI

Installed as:

`Dragonborn UI - SkyUI Reskin - Rhiven`

Version:

`0.80`

### FOMOD choices

- Desktop Splash: **Skip**
- Start Menu: **Cleaned, no logo**
- Character Creation Menu: **Skip**
- Quest and System Menu: **Knotwork patch - No Quicksave**
- Tween (Tab) Menu: **No Custom Skills Menu**
- Optional: **Sovngarde Font**
- Optional: **More Informative Console patch**

All other optional choices were left disabled for the first compatibility test.

## Conflict strategy

Expected behavior:

- Dragonborn UI wins mainly on visual UI assets such as SWF files, textures, icons and layouts.
- NEFARAM-specific functional patches and late loaders are allowed to win where required.
- Dragonborn UI should not be forced to overwrite every conflict blindly.

## Validation

**Status: VALIDATED**

In-game test completed successfully. Dragonborn UI integrates correctly with the current NEFARAM stack.

One remaining window is not yet reskinned. This is considered cosmetic only. The author also provides separate UI modules, so the missing window can be reviewed later during normal gameplay without blocking the setup.
