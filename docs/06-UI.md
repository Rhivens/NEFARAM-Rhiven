# 06 - User Interface

## Stock NEFARAM UI stack

NEFARAM already contains a substantial UI stack including SkyUI, SkyHUD, TrueHUD, Dear Diary Dark Mode, Infinity UI, Compass Navigation Overhaul, I4 / B.O.O.B.I.E.S support, Knotwork, More Informative Console and related patches.

The current strategy is **not** to dismantle the existing stack. Dragonborn UI and Rhiven-specific UI additions are installed lower in the left pane and allowed to overwrite the visual assets they are designed to replace.

## Wheeler stack

The older Rhiven setup used `dMenu + dMenu NG + Wheeler + Wheeler Refined`. For NEFARAM 17.3.6, the legacy dMenu chain was replaced by the newer Perfected Wheeler branch.

Current order in `04 - User Interface`:

1. `Wheeler - Quick Action Wheel Of Skyrim - Rhiven`
2. `Perfected Wheeler - Apocrypha Menu Framework - Rhiven`
3. `Dragonborn - Wheeler Reskin - Rhiven`
4. `Dragonborn - Wheeler Reskin Edge UI Color Options - Rhiven`

### Framework choice

Perfected Wheeler requires Wheeler plus one supported menu framework.

NEFARAM 17.3.6 already includes **SKSE Menu Framework**, so no separate Apocrypha Menu Framework, dMenu or dMenu NG installation was required.

Perfected Wheeler appears correctly in the SKSE **Mod Control Panel** opened from the NEFARAM SKSE Settings shortcut.

### Validation

## Conflict strategy

Expected behavior:

- Dragonborn UI wins mainly on visual UI assets such as SWF files, textures, icons and layouts.
- NEFARAM-specific functional patches and late loaders are allowed to win where required.
- Dragonborn UI should not be forced to overwrite every conflict blindly.
- Wheeler visual addons load after the functional Wheeler components.
