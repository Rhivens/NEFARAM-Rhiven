# Pama´s Permanent Crucifixes 2.0

Source: https://www.loverslab.com/files/file/15992-pama%C2%B4s-permanent-crucifixes/

## About This File

Pama´s Permanent Crucifixes provides a spell-driven system for creating persistent crucifixes anywhere in the world and assigning NPCs to them.

## What does this Mod?

- Construct crucifixes anywhere in the world via spell.
- NPCs placed on a cross remain there indefinitely, even after leaving the area.
- If left on the cross long enough, victims can die.
- Bodies remain on the crucifix until manually removed.
- The total number of victims across the world is effectively unlimited.
- Works on Essential actors and non-persistent actors such as generic bandits.
- NPC-only:
  - the Player Character cannot use the crucifix as victim.

## Limitations / Issues

- Live victims can occasionally be misaligned with their crosses despite the author's built-in correction functions.
- The total number of victims in the world is unlimited, but the author recommends a maximum of **5 victims per cell**.
- Exceeding 5 victims in a cell can cause game instability.

## Troubleshooting

The mod includes a diagnosis function.

Procedure:

1. Enable the Diagnosis dialogue option in the MCM.
2. Interact with the malfunctioning cross.
3. Select **Diagnosis**.
4. Record the output and include it in a bug report.

## Notes NEFARAM-Rhiven

- **Optional module**, not required by the Prison Alternative / PAMA core.
- Main use case is persistent NPC punishment / world decoration rather than prison-system integration.
- Persistent actors and corpses should be used conservatively in a large long-running save.
- Respect the author's limit of **5 victims per cell**.
- Avoid using named, quest-critical or otherwise important NPCs unless their quest/state implications are fully understood.
- Since the Player Character cannot use the crucifix, the mod adds no direct value to Eleanor's Prison Alternative experience.
- Current recommendation:
  - keep documented;
  - do not include in the initial PAMA core installation;
  - reconsider later only if persistent crucifixion as a sandbox/world feature is specifically desired.
